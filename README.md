# ToolShed

Skills, agents and prompts I use day to day for both work and play. Cleaned up and made tool-agnostic for sharing.

## What's in the shed

| Folder | What's in it |
|---|---|
| [`skills/`](skills/) | Reusable skills: instructions an AI tool can load to do one kind of task well |
| [`plugins/`](plugins/) | Bundles of skills you install together, like the kind team |
| [`agents/`](agents/) | Agent setups: roles, steps and tools for multi-step work |
| [`prompts/`](prompts/) | Standalone prompts you can copy and paste into any AI tool |
| [`notes/`](notes/) | The thinking behind each tool: why I built it, what changed, what I learned |

## Using anything here

Everything is plain markdown, so it works with any AI tool. Copy what you need and adapt it.
