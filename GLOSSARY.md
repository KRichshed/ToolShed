# ToolShed Glossary

Welcome. If you are new to GitHub or AI skills, these words can seem strange.
Here are thirteen key terms explained in plain words with everyday pictures.

## 1. Repository (repo)

- **What it is:** A project folder on GitHub. It holds all your files. It tracks every change over time.
- **Everyday picture:** Think of a shared filing box or tool shed. Everything you need lives in one tidy place.

## 2. Branch

- **What it is:** A safe copy of your project where you can try new changes.
- **Everyday picture:** Think of drawing on a photocopy. If you like the changes, you keep them. If not, you toss the copy away. The original file stays safe.

## 3. Commit

- **What it is:** A saved snapshot of your files. Each commit has a short note saying what you changed.
- **Everyday picture:** Think of saving a draft. You add a time stamp and a quick note to remind yourself what you did.

## 4. Pull request (PR)

- **What it is:** A polite request to merge your changes into the main project.
- **Everyday picture:** Think of handing a revised draft to a teammate. You ask them to review it before putting it into the team folder.

## 5. Issue

- **What it is:** A public message thread on GitHub. You use it to report a bug, ask a question, or share an idea.
- **Everyday picture:** Think of pinning a note to a team board. Everyone can see what needs attention.

## 6. README

- **What it is:** The main document at the top of a folder. It opens when someone visits the page.
- **Everyday picture:** Think of a welcome sign at the front door of a building. It shows you around.

## 7. Markdown

- **What it is:** A simple way to format plain text. You use basic keyboard marks, like hashes for titles and asterisks for bold text.
- **Everyday picture:** Think of typing a quick text. Simple marks turn into neat headings and tidy lists.

## 8. Prompt

- **What it is:** A single written question or request you type into an AI chat tool once.
- **Everyday picture:** Think of asking a colleague a quick question at their desk.

## 9. Skill (SKILL.md)

- **What it is:** A plain text file of instructions. A prompt you repeat often ladders into a skill so your AI tool handles that job the same way every time.
- **Everyday picture:** Think of a laminated recipe card or desk checklist you hand to a helper.

## 10. Agent

- **What it is:** A setup where several skills work together across steps, pausing for your review at each checkpoint.
- **Everyday picture:** Think of a small project crew where each person handles one step and checks with you before moving on.

## 11. Frontmatter

- **What it is:** A small block of details at the very top of a file, between three dashes. It lists items like the name, author, and version.
- **Everyday picture:** Think of a luggage tag on a bag. It tells you what is inside at a glance.

## 12. Token

- **What it is:** A tiny chunk of a word that an AI reads at one time. A token is often about four letters or half a word.
- **Everyday picture:** Think of reading a sentence word by word. AI tools count tokens to measure length and limits.

## 13. Level 1 Operator

- **What it is:** Our rule for how an AI skill behaves. It gathers, checks, and suggests, and never acts or publishes on its own. You make every decision.
- **Everyday picture:** Think of a satellite navigation screen in a car. It shows the map and suggests a turn, and your hands stay on the wheel.
