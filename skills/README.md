# Skills

Reusable instructions an AI tool can load to do one kind of task well.

Each skill has its own folder with two files:

- `README.md`: start here. It explains what the skill does and how to use it, step by step.
- `SKILL.md`: the instructions you give your AI tool.

| Skill | What it does |
|---|---|
| [intent-mirror](intent-mirror/) | Turns a messy brain dump into a short summary you check before the AI does anything |

Looking for the kind team? Those role skills are bundled as a plugin in [`plugins/kind-team`](../plugins/kind-team/).

New to skills? [How to add a skill](how-to-add-a-skill.md) shows how to use one in Claude, Google Gemini or ChatGPT.

New skill pages follow [README-template.md](README-template.md).
