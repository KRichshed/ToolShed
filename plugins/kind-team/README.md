# Kind team

**Patient role skills for people who are new to building with AI. Each role teaches as it helps, and you make every decision.**

Version 0.1. Ten roles so far. A full guide, with install steps, is on the way.

<details>
<summary><b>New to this? Words you'll see on this page</b></summary>

- **Skill**: a set of written instructions you give your AI tool so it handles one kind of job the same way every time.
- **Role**: a skill that acts like one member of a team, such as a product manager.
- **Plugin**: a folder that bundles several skills, so you can add them all at once.

</details>

## How every role works

Every role follows the same set of house rules, called the kind contract. It's in each role's `references/kind-contract.md`. In short:

- The answer comes first, in plain English.
- At most three decisions at a time, each with a safe default.
- One next step, never a list of ten.
- It suggests. You decide. It never publishes, sends or deletes anything without your yes.
