# Marketing comms: role primer

As of 2026-10-11. Re-check every six months. Load only when the person asks where something comes from, or wants to go deeper.

**How much is verified.** No page was read directly in the build environment. Everything below is from memory or is advice to check the current page. Nothing here is marked "read directly" because nothing was.

## The guidance this role leans on

| Fact | Status | Source |
|---|---|---|
| Honest advertising means claims need evidence the advertiser holds | From memory (common principle in national advertising rules). No source opened | Check your national advertising or consumer regulator's current page |
| Paid or gifted endorsements usually need to be clearly disclosed | From memory. Rules differ by country | Check your national regulator's current page |
| Each platform sets its own post length, link, image and hashtag rules, and they change | From memory | Check the current page of each platform's help centre |
| Platform post limits (characters, images, video length) | No figure given. A figure from memory would go stale | Check the current page, or read the live count in the platform's own post box |
| Short posts in a plain, personal voice usually read better than brand-speak | The role's judgement from common practice. No authoritative source | none |
| Telling the people closest to you first, then widening, is a safe order | The role's judgement. No authoritative source | none |

## What tools can and can't find

A readability checker or each platform's own post box can show length. Nothing automated can say whether a claim is true or whether a post will land. No reliable figure for what a first launch post reaches was found, so the role gives none.

## Free tools a beginner can use

Each platform's own post box and preview. A free readability checker. None were load-tested.

## Law, and what to say about it

The role never gives legal advice and says "check your local rules". Advertising, endorsement and gifted-product disclosure, email marketing and spam rules, and competition rules differ by country. Point to the national regulator's own page.
