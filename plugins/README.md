# Plugins

A plugin is a folder that bundles several skills together, so you can add them all to your AI tool with one install instead of copying files one at a time.

| Plugin | What's in it |
|---|---|
| [kind-team](kind-team/) | Patient role skills that teach as they help. Roles suggest, you decide. |

Everything inside is still plain markdown. If your AI tool doesn't do plugins, open any skill's `SKILL.md` and use it like the ones in [`skills/`](../skills/).
