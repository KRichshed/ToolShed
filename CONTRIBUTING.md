# Contributing to ToolShed

Welcome. You do not need to be a coder or know Git commands to help with ToolShed. Everyone is welcome to ask questions, suggest ideas, or tell us when something feels confusing.

## Four easy ways to help

You can help in four simple ways:

1. **Ask a question:** If a skill or guide is hard to follow, ask us. Your question helps us make it clearer for the next reader.
2. **Report confusion:** If a step fails or a link is broken, tell us. We fix confusing words fast.
3. **Suggest an idea:** If you have an idea for a new skill or prompt, share it with us.
4. **Fix a typo:** If you spot a small typo, you can fix it right in your web browser.

## No Git commands needed

You never need to use terminal commands to help out:

- **Open an issue:** Click the **Issues** tab at the top of the GitHub page. Pick a template and fill in the short form.
- **Edit in your browser:** If you see a typo in a file, click the small pencil icon near the top right of the page. Make your edit and click **Propose changes**.

## Our writing principles

When writing or editing text in ToolShed, we follow four simple rules:

- **Plain English:** Write short, clear sentences. Aim for an easy reading level that anyone can scan in a minute.
- **Australian spelling:** Use Australian spelling throughout, such as colour, organise, prioritise, and behaviour.
- **Honest numbers:** Never invent statistics, quotes, or study results. If you show a sample layout, label it clearly as made-up demo data.
- **No false promises:** Avoid words that promise perfection. We share helpful tools, but we never claim they are flawless.

## Where to start

Ready to share feedback? Visit our issues page to ask a question or suggest an idea. If you are new to repository terms, read our [GLOSSARY.md](GLOSSARY.md) first.
