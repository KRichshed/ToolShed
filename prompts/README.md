# Prompts

Single questions or instructions you can copy and paste into any AI chat tool.

## How prompts fit into the shed

A **prompt** is the first step on the ladder:

1. **Prompt (`prompts/`):** A single question or request you type once.
2. **Skill ([`skills/`](../skills/)):** When you repeat a prompt often, it grows into a reusable skill card (`SKILL.md`) so your AI tool follows the same rules every time.
3. **Agent ([`agents/`](../agents/)):** Several skills working together across multiple steps.
